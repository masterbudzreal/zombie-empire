# Building Zombie Empire

Everything builds on Windows with tools that ship with Windows or are free:
.NET Framework 4.x `csc.exe` (built into Windows), JDK 21, Python 3.12 with `numpy`, `scipy`, `Pillow`, `soundfile`.

```powershell
$csc = "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe"
```

## Mod (`mod/`)

Compile against the NeoForge 21.1.215 / Minecraft 1.21.1 client jars (Mojang mappings), e.g. from a Modrinth App or Prism install:

```powershell
$cp = "client-1.21.1-20240808.144430-srg.jar;neoforge-21.1.215-universal.jar;bus-8.0.5.jar;loader-4.0.42.jar"  # + authlib, brigadier, datafixerupper, guava, gson, netty
javac --release 21 -encoding UTF-8 -cp $cp -d out mod\src\main\java\zombieempire\ZombieEmpireMod.java
Copy-Item mod\src\main\resources\* out -Recurse
jar --create --file zombieempire-1.1.2.jar -C out .
```

The soundtrack in `mod/src/main/resources/assets/zombieempire/sounds/music` is generated by `tools/compose_soundtrack.py <out_dir>`.

## Launcher (`launcher/`)

```powershell
& $csc /nologo /target:winexe /optimize /win32icon:assets\zombieempire.ico /out:ZombieEmpire.exe /r:System.Windows.Forms.dll /r:System.Drawing.dll launcher\ZombieEmpire.cs
```

Goes next to a portable Prism Launcher with the instance in `instances\ZombieEmpire`, plus `ZombieEmpire.ini`, `mods.txt` and `CREDITS.txt`.

## Standard installer (`installer/`)

1. Zip the full Standard game folder (Prism portable + instance + `ZombieEmpire.exe`, without third-party mods) as `payload.zip`.
2. Use a 256 px PNG of the icon as `logo.png`.

```powershell
& $csc /nologo /target:winexe /optimize /win32icon:assets\zombieempire.ico /resource:payload.zip,payload.zip /resource:logo.png,logo.png /out:ZombieEmpire-Setup.exe /r:System.Windows.Forms.dll /r:System.Drawing.dll /r:System.IO.Compression.dll /r:System.IO.Compression.FileSystem.dll installer\Setup.cs
```

Silent options for testing: `/silent /dir="C:\path" /nolaunch /noshortcuts`; uninstall: `Uninstall.exe /uninstall /silent`.

## Lite (`lite/`)

`tools/build_lite.py <release_dir> <mod_jar> <icon_png> lite <pkg_dir> <zip_out>` assembles `install.bat`, `install.ps1`, `README.txt`, `mods.txt`, `CREDITS.txt`, the icon and the `files\` folder (mod, configs, `bossworld` map).

Test without touching your own `.minecraft`:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -MinecraftDir C:\temp\test-minecraft -Yes
```

## Website (`site/`)

Static page; images and music are served from this repository through jsDelivr
(`https://cdn.jsdelivr.net/gh/masterbudzreal/zombie-empire@main/site/assets/...`).
Art is generated by `tools/make_site_art.py` and `tools/make_icon.py`.
Pushing to `site/` on `main` deploys it to InfinityFree via `.github/workflows/deploy-site.yml`.

## Release

```powershell
gh release create vX.Y Zombie-Empire-vX.Y-Standard.zip Zombie-Empire-vX.Y-Lite.zip --title "Zombie Empire vX.Y" --notes-file notes.md --latest
```

Then update `VERSION`, `STANDARD_URL`, `LITE_URL` and the sizes at the top of `site/index.html`.
