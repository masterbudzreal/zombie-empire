ZOMBIE EMPIRE v1.1 Standard - Minecraft 1.21.1 + NeoForge 21.1.215

INSTALL
  1. Run ZombieEmpire-Setup.exe and click INSTALL & PLAY.
     If Windows shows "Windows protected your PC": click "More info" -> "Run anyway".
  2. The game starts right away. First launch only:
     - the mods download from Modrinth (official source);
     - log in with your Microsoft account (a legit Minecraft: Java Edition is required);
     - Java, Minecraft and NeoForge install automatically.
  3. Next times: open "Zombie Empire" from the desktop or the Start menu.

No admin rights needed. Default folder: %LOCALAPPDATA%\Programs\Zombie Empire
Uninstall: Windows Settings -> Apps -> Zombie Empire.

ON LAUNCH
  - If the official server zombieempire.serveminecraft.net is online, you join it.
  - Otherwise the "bossworld" map starts in singleplayer, at the hub, in adventure mode,
    and opens to LAN on port 25565 so friends can join.

Settings: ZombieEmpire.ini in the install folder. Credits and licenses: CREDITS.txt
