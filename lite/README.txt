ZOMBIE EMPIRE v1.1 LITE - Minecraft 1.21.1 + NeoForge 21.1.215

The Lite version installs Zombie Empire into the Minecraft launcher you already use
(no Prism Launcher). A legit copy of Minecraft: Java Edition is required.

INSTALL
  1. Extract this zip anywhere.
  2. Double-click install.bat and press Enter to use your default .minecraft folder
     (or type another game folder). It will:
       - install the official NeoForge 21.1.215 into versions\
       - download the 28 mods from Modrinth into mods\ (other mods are moved to mods-backup-...)
       - copy the configs and add the "bossworld" map to singleplayer
       - create the "Zombie Empire" launcher profile with 4 GB of RAM
  3. Open your Minecraft launcher, pick the "Zombie Empire" profile and play.
     Singleplayer -> "bossworld". Official server: zombieempire.serveminecraft.net

Java: install.bat uses the Java that comes with the Minecraft launcher (start Minecraft 1.21.1
once first) or any installed Java 17+. If none is found: https://adoptium.net (Temurin 21).

Works with any launcher that uses a .minecraft folder and launcher_profiles.json
(official Minecraft Launcher included).

LITE vs STANDARD
  Standard (ZombieEmpire-Setup.exe) also joins the official server automatically when it's
  online, puts you back at the hub every launch and empties the inventory on first launch.
  Lite: add the server from Multiplayer; the map starts at the hub with an empty inventory.
  Both: original soundtrack, welcome title and automatic LAN on port 25565 in singleplayer.

UNINSTALL
  Delete versions\neoforge-21.1.215, the mods listed in mods.txt plus zombieempire-1.1.2.jar,
  saves\bossworld, and the "Zombie Empire" profile in your launcher.

Third-party mods are not included: they are downloaded from Modrinth. Credits: CREDITS.txt
