ZOMBIE EMPIRE - Minecraft 1.21.1 + NeoForge 21.1.215

HOW TO PLAY
  Open "Zombie Empire" from the desktop or the Start menu (or ZombieEmpire.exe in this folder).
  First launch only:
    - the mods are downloaded from Modrinth (official source, takes a minute);
    - Prism Launcher asks you to add an account: choose Microsoft and log in
      (a legit copy of Minecraft: Java Edition is required);
    - Java 21, Minecraft and NeoForge are downloaded automatically.

WHAT HAPPENS ON LAUNCH
  - If the official server zombieempire.serveminecraft.net is online, you join it.
  - Otherwise you start the "bossworld" map in singleplayer, at the hub, in adventure
    mode, and the world is opened to LAN on port 25565 so friends can join.
  - First time on a PC: empty inventory and a welcome title.

SETTINGS (ZombieEmpire.ini)
  server=, world=, hub=, gamemode=, lanport=, music=, welcome_title=

PLAYING WITH FRIENDS OVER LAN
  Same network: Multiplayer -> the world shows up, or connect to <host PC IP>:25565.
  Over the internet: forward port 25565 on the host's router.

UNINSTALL
  Windows Settings -> Apps -> Zombie Empire -> Uninstall.

Requirements: Windows 10/11 64-bit, 8 GB RAM recommended.
