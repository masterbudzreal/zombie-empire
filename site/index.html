FAQ //

Is it free?

Yes, completely. You only need your own copy of Minecraft: Java Edition.

Standard or Lite?

Standard if you want everything automatic, including joining the official server. Lite if you prefer to keep playing from the Minecraft launcher you already use.

Windows says the file is unrecognized

The installer isn't code-signed yet, so SmartScreen warns about it. Click More info → Run anyway. No admin rights are needed.

install.bat says Java was not found

Start Minecraft 1.21.1 once from your launcher (it installs its own Java), or install Java 21 from adoptium.net, then run install.bat again.

Where do the mods come from?

They are downloaded during install straight from Modrinth, so every mod author gets credit for their downloads. The full list with authors and licenses is in CREDITS.txt.

How do I uninstall it?

Standard: Windows Settings → Apps → Zombie Empire → Uninstall. Lite: remove the Zombie Empire profile, versions\neoforge-21.1.215, the mods and saves\bossworld from your .minecraft (see README.txt).

Mac or Linux?

Not yet: both versions are Windows-only for now.
